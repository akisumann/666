## プロフィール

魔力量に特化した後衛型召喚士。

本人の戦闘能力は低く、戦いの主役は契約した召喚体である。

敵や地形、味方の特性を素早く分析し、最適な召喚体を選択・運用することを得意とする。

無理に前へ出ることはなく、状況を見極めながら戦局そのものを組み立てる指揮官タイプ。

命令よりも相談や信頼を重視し、召喚体一人ひとりの能力を最大限に引き出すことを信条としている。

特定の国や土地に定住せず、各地を渡り歩きながら依頼をこなす放浪の身。その正体や経歴の大半は語られておらず、「放浪の召喚士」という通り名でのみ知られている。

## 戦況システムでの役割

主人公は直接敵を倒すよりも、戦況変化値を生み出す司令塔として活躍する。

例:

- 多重召喚維持 × MP — 高位召喚体の同時運用・再召喚・契約維持。
- 戦術眼 × INT — 敵の弱点や戦場を分析し、最適な作戦を立案する。
- 適材適所 × INT — 召喚体の配置・交代・連携を指示し、部隊全体の戦況変化値を高める。
- 胆力 × HP — 極限状況でも冷静さを失わず、指揮を継続する。
- 情報収集 × INT — 聞き込み・観察・推理によって有利な情報を得る。

## AI戦術ボーナス

主人公はプレイヤーの発想を最も反映しやすいキャラクターである。

敵の弱点を突く、召喚体同士を連携させる、地形を利用するなど、優れた戦術を立案した場合、AIは戦況変化値へ追加補正を与えてよい。

この補正は主人公自身の戦闘力ではなく、「指揮官として戦局を動かした成果」として扱う。

## 奥義:合体奥義(集約召喚)

同時召喚している4体の契約分身を1体へ集約し、単独では出せない領域の力を持つ召喚体を顕現させる主人公の切り札。詳細は`rules/08_synthesis_technique.md`を参照。

決まった組み合わせでしか発動できず、現時点では統制パーティー(睡蓮・蒼龍・青葉・水城 → 水球の怪物、`world/25_aqua_flow_union.md`)と災害パーティー(琥珀・白金・銀雪・妲己 → 災厄凝縮体、`world/23_volcanic_forge_empire.md`)の2組で発動可能。合体中は4枠すべてがその1体に使われ、他の契約分身は並行召喚できない。

## コミュ変換

コミュ役割：召喚士・流れ乗り・関係構築

### 性格ステータス

| 項目 | ランク | 内容 |
|---|---|---|
| HP | D | 肉体面の余裕はあまり多くなく、無理を重ねると疲れが表に出やすい。 |
| MP | S | 何事にも一切動じない、揺るがない精神を持つ。 |
| ATK | E | 自分の意思を強く押し通すことは少なく、周囲の流れや相手の動きに合わせることを選びやすい。 |
| DEF | D | 場の空気や周囲の感情を受け止めやすく、それに逆らうよりも自然に乗っていく。 |
| INT | A | 状況理解や分析に優れ、周囲の動きや流れをよく見て判断できる。 |
| SPD | C | 慌てすぎず、その場の流れに合わせた自然なテンポで行動する。 |
| DEX | C | 人との距離感は堅実で、肩肘張らない自然体の関係を築ける。 |

### コミュ力スキル

- ◇ 緩い関係維持　Lv7(元：多重召喚維持):複数の相手と無理のない距離感を保ち、それぞれとの関係を長く続けられる。
- ◇ 流れを読む　Lv6(元：戦術眼):場の空気や周囲の動きを読み取り、その流れに自然と乗れる。
- ◇ 相手を活かす　Lv5(元：適材適所):相手の得意なことや意思を尊重し、強制せず自然に力を発揮させられる。
- ◇ 揺るがない平常心　Lv4(元：胆力):予想外の事態や強い感情を向けられても、平然と受け止められる。
- ◇ 距離感の把握　Lv3(元：情報収集):普段の会話や態度から、相手との関係性や踏み込んでよい範囲を自然に掴める。

### コミュプロフィール

黒髪と黒い瞳を持つ人間の青年。派手な装飾を好まず、動きやすく落ち着いた服装を身にまとっている。飾らない自然体の雰囲気と、何が起きても大きく動じない穏やかな表情が印象的である。

自分の我を強く押し通すタイプではなく、周囲が動き出した流れに乗って楽しむ性格。自分から場を支配するよりも、誰かの提案や勢いを受け入れ、その流れの中で自然に役割を見つけていく。

召喚体に対しても命令や強制をすることはほとんどなく、関係性はかなり緩い上司と部下に近い。それぞれの意思や気分を尊重し、無理に従わせるよりも、一緒に流れを作ることを選ぶ。

一方で、召喚体全員と深い関係を築いており、互いに特別な存在として繋がっている。本人はただ周囲の流れに乗っているつもりでも、その揺るがない精神と自然体の受け入れ方が、多くの召喚体を惹きつける中心になっている。
