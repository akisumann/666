## ステータス

| 項目 | ランク | 内容 |
|---|---|---|
| HP | D | 前衛に立てる体力はない。後方で行動する分には問題ない。 |
| MP | S | 規格外の魔力量。高位召喚体を最大4体同時に維持できる。 |
| ATK | E | 自前の攻撃手段はほぼない。護身用の短剣程度。 |
| DEF | D | 軽装で打たれ弱いが、危険察知と退避判断は速い。 |
| INT | A | 分析・推理・作戦立案・召喚体運用に優れる。 |
| SPD | C | 身体能力は平均以上。後衛として十分な機動力を持つ。 |
| DEX | C | 召喚契約や魔力制御は得意だが、超人的ではない。 |

合計：50(Lv相当)

## プロフィール

魔力量に特化した後衛型召喚士。

本人の戦闘能力は低く、戦いの主役は契約した召喚体である。

敵や地形、味方の特性を素早く分析し、最適な召喚体を選択・運用することを得意とする。

無理に前へ出ることはなく、状況を見極めながら戦局そのものを組み立てる指揮官タイプ。

命令よりも相談や信頼を重視し、召喚体一人ひとりの能力を最大限に引き出すことを信条としている。

## 戦況システムでの役割

主人公は直接敵を倒すよりも、戦況変化値を生み出す司令塔として活躍する。

例:

- 多重召喚維持 × MP — 高位召喚体の同時運用・再召喚・契約維持。
- 戦術眼 × INT — 敵の弱点や戦場を分析し、最適な作戦を立案する。
- 適材適所 × INT — 召喚体の配置・交代・連携を指示し、部隊全体の戦況変化値を高める。
- 胆力 × HP — 極限状況でも冷静さを失わず、指揮を継続する。
- 情報収集 × INT — 聞き込み・観察・推理によって有利な情報を得る。

## AI戦術ボーナス

主人公はプレイヤーの発想を最も反映しやすいキャラクターである。

敵の弱点を突く、召喚体同士を連携させる、地形を利用するなど、優れた戦術を立案した場合、AIは戦況変化値へ追加補正を与えてよい。

この補正は主人公自身の戦闘力ではなく、「指揮官として戦局を動かした成果」として扱う。
