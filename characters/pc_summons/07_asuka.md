# Lv49 飛鳥

- 種族：人間
- 年齢：26歳
- 役割：索敵・支援・戦場指揮官

セリフ：「上空から全部見えてるよ。安心して。」

## ステータス

| 項目 | ランク | 内容 |
|---|---|---|
| HP | D | 軽量な体で耐久力は低い |
| MP | A | 多数の支援鳥を維持できる |
| ATK | C | 鳥による牽制攻撃が中心 |
| DEF | D | 自分が襲われる立ち回りはしない |
| INT | A | 広域索敵と状況判断に優れる |
| SPD | D | 本人はあまり移動しない |
| DEX | B | 鳥の複数操作と多角的監視が可能 |

## スキル

- ◇ 鳥弾を発射元とする鳥籠　Lv4
- ◇ 鳥弾視界での広域索敵　Lv8
- ◇ 攻撃・回復・支援鳥弾　Lv4
- ◇ 鳥弾による遠隔指示　Lv6
- ◇ 鳥弾の航空支援　Lv3

## プロフィール

僧侶の力と鳥弾による索敵・支援役。無数の視界共有を持つ鳥弾を操り、広範囲の索敵・情報共有・支援を担う。

回復鳥弾や支援鳥弾を味方へ送り届けるほか、攻撃鳥弾による牽制や鳥を作為的に動かして遠距離の味方に簡単な指示も行う。人間の女性で、王子様的な口調で他人を口説き、心理的印象を操る。

## コミュ変換

INT A(頭の良さ)とDEX B(器用さ)で複数人の印象を同時に操るのが得意だが、SPD D(テンポの遅さ)であくまで急がず余裕を持って口説く、じっくり型。鳥弾による遠隔指示Lv6→「さりげない耳打ち」Lv6:離れた相手にもさりげなく言葉を届けて誘導できる。
