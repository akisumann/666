# Lv49 唯一(ゆいいつ)

- 種族：人間
- 年齢：22歳
- 役割：広域削りアタッカー(剣士)

セリフ：「横に斬れば、だいたい当たるっす!」

## ステータス

| 項目 | ランク | 内容 |
|---|---|---|
| HP | C | 普通の前衛程度の耐久 |
| MP | S | 遠隔斬撃を好き放題に連発できる |
| ATK | B | 横一線斬撃による広域火力 |
| DEF | C | 普通の剣士防御 |
| INT | E | 細かい判断は苦手 |
| SPD | C | 機動力は普通 |
| DEX | C | 剣の扱いは普通 |

## スキル

- ◇ 遠隔範囲斬撃　Lv8
- ◇ 広域斬撃連打　Lv6
- ◇ タメなし並火力斬撃　Lv3
- ◇ 見た目のヤバさ　Lv4
- ◇ 単純作業適正　Lv3

## プロフィール

横一線の遠隔斬撃を飛ばすことに特化した女性剣士。お気楽天然な田舎者で、難しいことはあまり考えない。

剣を横に振りまくるだけで広範囲をまとめて削れるが、細かい狙いや味方への配慮は苦手。本人は「横に斬れば大体当たる」と本気で思っており、雑だが戦場が噛み合うと非常に強い。

また遠隔斬撃を連打する様は誰が見てもヤバさがわかるため、戦意の低い盗賊や野良モンスターは軽く3〜4回振るだけで相手が逃げる。

## コミュ変換

MP S(精神面の余裕が最高峰)で何があっても気にせずケロッとしているが、INT E(細かい判断が苦手)で言うことも大味でニュアンスが伝わりにくい。見た目のヤバさLv4→「強気な態度」Lv4:自信満々に見えるので、なぜか周りが勝手に警戒してくれる。
