# Lv49 九重(ここのえ)

- 種族：人間
- 年齢：24歳
- 役割：中距離制圧

セリフ：「九で終わらせるのが、美しいでござる。」

## ステータス

| 項目 | ランク | 内容 |
|---|---|---|
| HP | D | 魔導士としては平均の体力 |
| MP | A | 九本の属性槍を運用できる |
| ATK | A | 一投ごとの威力が非常に高い |
| DEF | D | 近接戦・防御は苦手 |
| INT | C | 頭脳は普通 |
| SPD | D | 足は速くない |
| DEX | B | 高精度の投槍技術を持つ |

## スキル

- ◇ 属性付与投槍　Lv6
- ◇ 氷or雷or風or炎付与　Lv6
- ◇ 九槍戦術　Lv4
- ◇ 自滅の代わりの強化第十槍　Lv4
- ◇ 投槍術　Lv4

## プロフィール

全属性を扱う投槍魔導士。量産品の投げ槍に炎・風・氷・雷を状況に応じて付与して使い分け、直撃ダメージと範囲ダメージを与える。

通常は九本の槍のみで戦い、第十槍は自滅する代わりに火力を増幅した必殺技として扱う。

武士口調で「〜でござる」と話すが、これは本人なりの美学による振る舞いであり、焦ると素の現実的な性格が表に出る。第十槍を「敗北」と呼ぶのも美学だけではなく、「撃ったら自分が終わる」という切実な理由がある。
