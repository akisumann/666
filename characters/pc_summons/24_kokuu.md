# Lv50 黒羽(こくう)

- 種族：天狗
- 年齢：22歳
- 役割：高速近接・風属性アタッカー

セリフ：「命令がなくとも、やるべきことは見える。規律を乱さず、速やかに片付ける。」

## ステータス

| 項目 | ランク | 内容 |
|---|---|---|
| HP | C | 前線に出られるだけの体力はあるが、重装型ではない |
| MP | C | 風は主に飛行にしか使わない |
| ATK | B | 高速接近からの斬撃と蹴撃に優れる |
| DEF | C | 防御はほどほど。回避と位置取りで攻める |
| INT | B | 任務目的と自分の役割を理解し、自分で判断して動ける |
| SPD | A | 地上・空中ともに非常に速い |
| DEX | C | 高速移動中でも不自由なく攻撃できる |

## プロフィール

天狗の女性、眼鏡をかけた真面目な委員長タイプ。指示待ちではなく、自分で状況を見て動く。姿勢がよく、言葉遣いは少し硬め。性格は厳格、几帳面、責任感が強い。規律の乱れには眉をひそめるが、他人を咎めることはない。

戦い方は、空を飛び、刀で斬り込むヒット&アウェイ、風は飛行と位置取りに使い、素直な抜刀術で敵を斬る。命令がなくても、任務目的から逆算してチームでの自分の役割を見つけられる。

## コミュ変換

INT B(頭の良さ)で場の状況を的確に読み、SPD A(テンポの速さ)で判断も行動も早い。俯瞰視点Lv5→「客観視」Lv5:一歩引いて場を見渡し、今何が求められているかをすぐ把握する。
