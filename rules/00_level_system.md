# レベルシステム

## レベルとは

レベルとは、この世界に存在する全ての生命が持つ実力の指標である。

レベルは生物・魔物を問わず共通の基準であり、成長や鍛錬によって上昇する。

レベルの上限は100である。

## レベルの役割

レベルは、その存在が持つ総合的な実力を表す。

ただし、勝敗を決定する唯一の要素ではない。

実際の強さは、

- レベル
- ステータス
- スキル

の3項目を基準として決定される。

さらに、

- 魔法
- 装備
- 経験
- 戦術
- 相性
- 地形
- 種族特性
- 契約・加護
- その他の特殊能力

などが補助要素として戦闘結果に影響する。

## レベル帯の目安

| レベル | 目安 |
|---|---|
| Lv1〜10 | 一般人・駆け出し |
| Lv11〜20 | 下級冒険者・一般兵士 |
| Lv21〜30 | 一人前の冒険者・熟練兵 |
| Lv31〜40 | ベテラン・地方の実力者 |
| Lv41〜50 | 地方上位・精鋭クラス |
| Lv51〜60 | 国家上位・騎士団長・宮廷魔導士・高ランク冒険者 |
| Lv61〜70 | 英雄級・国家の切り札 |
| Lv71〜80 | 大陸でも名の知れた超一流 |
| Lv81〜90 | 伝説級 |
| Lv91〜99 | 神話級 |
| Lv100 | 理論上の最高到達点 |

## 世界における分布

- Lv1〜30が世界の大多数を占める。
- Lv40以上は優れた実力者として知られ、地域社会でも高い評価を受ける。
- Lv50以上は希少ではあるが、世界規模で見れば珍しすぎる存在ではない。
- 小国・地方組織であっても、Lv50以上の実力者を最低1人以上抱えていることは珍しくない。
- 大国・巨大組織・宗教組織・魔法学園・騎士団などには、Lv50以上の実力者が複数所属している場合も多い。
- Lv60以上の英雄級は希少であり、国や組織を代表する切り札として扱われる。
- Lv70以上は世界でも限られた超一流の存在となる。

## レベル差

レベル差は戦闘結果へ大きく影響する。

しかし、レベルだけで勝敗が決定することはない。

ステータス・スキル・魔法・装備・戦術・相性・地形などによって格上へ対抗、あるいは格下へ敗北する可能性も存在する。

## 運用方針

レベルは世界共通の実力指標である。

新たな種族・国家・組織・魔物・キャラクターを追加する際は、本レベルシステムを基準として扱う。
