# アイテムシステム(フレーバー)

現時点でのアイテムは、戦闘判定(`rules/03_combat_system.md`)に数値的な影響を与えない、世界観・キャラクター描写のためのフレーバー要素として扱う。

## 位置づけ

- キャラクターのステータス・スキルは、既にその武具を使いこなした結果としての数値である。例えば仁礼の「ダブルメイス」というスキル名は武器そのものではなく、その武器を扱う技術を指す。
- アイテムは「このキャラが具体的に何を持っているか」を記述するための補助であり、ステータスやスキルのランク・Lvを変更するゲーム的な強化要素ではない。
- 将来的に装備による数値補正を導入したくなった場合は、このルールを拡張する形で別途定義する(現時点では未定・優先度低)。

## カテゴリ

- 武器：近接武器、遠隔武器、魔法媒体など
- 防具：鎧、盾、装飾品など
- 消耗品：薬、道具、食料など
- 魔道具：契約・召喚に関わる特殊な道具、遺物など

## 記述フォーマット

```
# アイテム名

- 分類：(武器/防具/消耗品/魔道具)
- 所有者：(キャラクター名、または「未所持」)
- 由来：(誰が作った/どこで手に入れたか)

## 説明

外見・素材・特徴などの説明文。
```

## 運用方針

- 既存キャラクターの装備(仁礼のダブルメイス、白金の機械腕、琥珀が生み出す薬品、芍薬が精製する鉱石など)を、このフォーマットで`items/`に書き起こしていく。
- 新しいアイテムは、キャラクター追加時や会話の流れで自然に発生したものから随時追加してよい。
- レアリティ・数値的な強さの評価は現状では設けない。フレーバーとして必要になれば改めて検討する。

### 主人公・召喚体と、一般冒険者との扱いの違い

上記の「フレーバー」という位置づけは、主に主人公(召喚士)と契約召喚体に当てはまる。召喚体のステータスは契約召喚のレベル同期(`rules/04_summoning_magic.md`)によって決まる特殊な数値であり、武器・防具の見た目や質を変えても戦闘力そのものは変わらない。

一方、バルトのような一般の門衛・冒険者・NPCにとっては、武器・防具は単なる見た目ではなく実戦力に直結する現実的な装備として扱う。`world/06_economy.md`の武器・防具の価格帯(粗悪〜英雄級)は、まさにこの「装備の質がそのまま強さに影響する」層を想定した価格差である。良い装備を買う・修理する・特注する、といった行動は一般冒険者にとって意味のある投資になる。

つまり、装備が「数値に影響しないフレーバー」か「実質的な強さの一部」かは、そのキャラクターが召喚体側か一般キャラクター側かによって扱いが分かれる。ステータス欄に細かい装備補正ルールを設けるわけではないが、描写上はこの違いを踏まえる。
