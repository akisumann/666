# アイテムシステム

主人公・契約召喚体にとってアイテムは、戦闘判定(`rules/03_combat_system.md`)に数値的な影響を与えない、世界観・キャラクター描写のためのフレーバー要素として扱う。一方、一般冒険者・NPCの装備、および消耗品については、下記の通り判定へ小さな数値補正を与える。

## 位置づけ

- キャラクターのステータス・スキルは、既にその武具を使いこなした結果としての数値である。例えば仁礼の「ダブルメイス」というスキル名は武器そのものではなく、その武器を扱う技術を指す。
- アイテムは「このキャラが具体的に何を持っているか」を記述するための補助であり、ステータスやスキルのランク・Lvを変更するゲーム的な強化要素ではない。
- 将来的に装備による数値補正を導入したくなった場合は、このルールを拡張する形で別途定義する(現時点では未定・優先度低)。

## カテゴリ

- 武器：近接武器、遠隔武器、魔法媒体など
- 防具：鎧、盾、装飾品など
- 消耗品：薬、道具、食料など
- 魔道具：契約・召喚に関わる特殊な道具、遺物など

## 記述フォーマット

```
# アイテム名

- 分類：(武器/防具/消耗品/魔道具)
- 所有者：(キャラクター名、または「未所持」)
- 由来：(誰が作った/どこで手に入れたか)
- 使用回数：(消耗品の場合のみ。1回使い切り/数回分など)
- 効果：(消耗品の場合のみ。該当判定への補正や直接効果)

## 説明

外見・素材・特徴などの説明文。
```

## 運用方針

- 既存キャラクターの装備(仁礼のダブルメイス、白金の機械腕、琥珀が生み出す薬品、芍薬が精製する鉱石など)を、このフォーマットで`items/`に書き起こしていく。
- 新しいアイテムは、キャラクター追加時や会話の流れで自然に発生したものから随時追加してよい。
- レアリティ・数値的な強さの評価は現状では設けない。フレーバーとして必要になれば改めて検討する。

### 主人公・召喚体と、一般冒険者との扱いの違い

上記の「フレーバー」という位置づけは、主に主人公(召喚士)と契約召喚体に当てはまる。召喚体のステータスは契約召喚のレベル同期(`rules/04_summoning_magic.md`)によって決まる特殊な数値であり、武器・防具の見た目や質を変えても戦闘力そのものは変わらない。

一方、バルトのような一般の門衛・冒険者・NPCにとっては、武器・防具は単なる見た目ではなく実戦力に直結する現実的な装備として扱う。`world/06_economy.md`の武器・防具の価格帯(粗悪〜英雄級)は、まさにこの「装備の質がそのまま強さに影響する」層を想定した価格差である。良い装備を買う・修理する・特注する、といった行動は一般冒険者にとって意味のある投資になる。

つまり、装備が「数値に影響しないフレーバー」か「実質的な強さの一部」かは、そのキャラクターが召喚体側か一般キャラクター側かによって扱いが分かれる。

### 一般キャラクターの装備スロットと補正

主人公・召喚体を除く一般冒険者・NPCについては、装備を「武器」「防具」の2枠で管理し、`rules/03_combat_system.md`の戦況変化値へ品質に応じてそれぞれ多少の補正を与える。

| 品質 | 戦況変化値への補正 |
|---|---|
| 粗悪 | 補正なし(状況次第でむしろ足かせになる場合もある) |
| 並 | 補正なし(基準) |
| 良質 | +1 |
| 特殊素材 | +2 |
| 高位魔道 | +3 |
| 一点物・英雄級 | +4〜+5 |

品質帯は`world/06_economy.md`の武器・防具の価格帯にそのまま対応する。

- 武器枠は、その武器を用いた攻撃・近接/遠隔系の判定にのみ補正を与える。
- 防具枠は、防御・被弾に関わる判定にのみ補正を与える。
- 2枠の補正は合算せず、それぞれの用途で使われた判定にのみ個別に適用する。
- この補正は`rules/03_combat_system.md`のAI戦術ボーナス(+5〜+20程度)とは別枠の、小さな下支えとして扱う。

### 消耗品の使用回数と補正

消耗品(回復薬、松明、聖水など)は、装備のような恒常的な補正ではなく、使用回数が決まった一時的なプラス判定として扱う。使い切ると効果は無くなる。

| 使用回数 | 効果の目安 |
|---|---|
| 1回(使い切り) | 該当する判定へ+2〜+3程度、または直接的な効果(HP回復など)を与える |
| 数回分(3〜5回程度) | 該当する判定へ+1〜+2程度を与える |

例:

- 回復薬：使用時にHPを回復させる、または治療系の判定に+2〜+3程度。1回使い切り。
- 松明：暗所での索敵・行動判定に+1程度。数回分(燃焼時間の目安)。
- 聖水：アンデッド・呪い関連の判定に+2程度。数回分。

消耗品は武器・防具の恒常補正と異なり、その場限りの行動として主人公・召喚体を含む全キャラクターが使用できる(フレーバー限定ルールの対象外)。

新しい消耗品を`items/`へ記録する際は、記述フォーマットの説明文中に「使用回数」「効果」を明記する。
