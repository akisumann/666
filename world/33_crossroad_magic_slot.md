# 魔導スロット

クロスロード・カジノ(`world/28_crossroad_casino.md`)にある遊戯機。絵柄を3つ揃える、シンプルで早い賭博。

## 基本

- 1回：100G
- 絵柄：剣 / 盾 / 宝石 / 星 / 竜 / 王冠
- 1回ごとに絵柄を3つランダム抽選する
- 結果は乱数(ダイス)で決定する(`world/28_crossroad_casino.md`の「運用ルール:主人公がカジノで遊ぶ場合」に準拠。主人公が遊ぶ場合も物語都合では決めない)

## 配当

| 結果 | 配当 |
|---|---|
| 3つ全部バラバラ | 負け -100G |
| 2つ同じ | 小当たり +50G |
| 3つ同じ | 当たり +300G |
| 竜・竜・竜 | 大当たり +800G |
| 王冠・王冠・王冠 | 特大当たり +1200G |

## 表示形式

```
魔導スロット：100G × ○回

1回目：絵柄・絵柄・絵柄 → 結果 ±○G
2回目：絵柄・絵柄・絵柄 → 結果 ±○G
3回目：絵柄・絵柄・絵柄 → 結果 ±○G

今回の収支：±○G
カジノ通算収支：±○G
```

## 演出

- 3つ同じが出たら、台が光る。
- 竜3つは派手な咆哮演出。
- 王冠3つは特大演出で周囲がざわつく。
- 小当たりは軽く光る程度。
- 負け続きなら女給や周囲の客が軽くコメントする。
